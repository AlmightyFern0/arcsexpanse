# Expanse by Arc's — Setup per testing

## Requisiti

- [Node.js](https://nodejs.org) versione 18 o superiore
  - Per verificare se è già installato: apri il terminale e digita `node --version`
  - Se non è installato, scaricarlo dal link sopra e seguire l'installazione guidata

## Avvio

1. Apri il terminale nella cartella del progetto
2. Installa le dipendenze (solo la prima volta):
   ```
   npm install
   ```
3. Avvia il progetto:
   ```
   npm run dev
   ```
4. Apri il browser su **http://localhost:3000**

## Note

- Il progetto gira in locale, non serve una connessione internet particolare
- Per fermarlo: `Ctrl + C` nel terminale
